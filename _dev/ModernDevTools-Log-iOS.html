Modern Dev Tools — iOS spatial studies

Three restyles of the modern debug log (Window_ModernLog) in Apple's iOS dark-mode language — flat bold type, semi-rounded surfaces, grouped inset lists, segmented controls, real switches, vibrancy trays, elevation instead of borders. Structure is unchanged: message list + inspector + add-on tray. Content parity is exact — three filter chips with counts, search, the six toolbar actions, the three state toggles, the mods-changed indicator, the compat-hint strip, the timestamp column and x12+395 repeat chips, and the full inspector (impact banner, copy actions, likely-source rows with state tags, diagnoses with Ignore, the report/fix pair, and the stack trace).
